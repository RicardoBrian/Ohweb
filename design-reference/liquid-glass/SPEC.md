✅ = Figma에서 직접 읽은 값, ≈ = Figma 호출 한도 때문에 HIG 기준으로 추정한 값.

## 핵심 원칙 (v1 "개구리" 문제 해결)
- 바탕은 **거의 불투명한 흰색(다크: #1e1e1e) "창"**. 색 덩어리 배경 없음.
- 유리는 **떠 있는 것에만**: 사이드바, 오른쪽 인스펙터, 툴바 컨트롤 캡슐, 모바일 탭바.
- 현황 카드·표·입력칸은 유리가 아님 → 얇은 회색 채움 또는 흰 바탕.
- 색은 시스템 파랑 하나 + 상태 점(초록/회색/빨강)만.

## v3 — "리퀴드 글래스로 안 보인다" 피드백 반영 (students-v3.html)

v2가 유리로 안 보인 이유: ① 뒤에 비칠 게 없음(흰 바탕) ② 흐림 24px + 흰 67%로 너무 뿌염 ③ 테두리 반사 없음.

층 구조:
1. **벽지** — 한 가지 색조. `?b` 차분한 파랑(macOS 26 기본 벽지 계열), `?a` 중성 회색.
2. **흰 내용 판 = 창** — 불투명, 모서리 26, 표·현황은 여기.
3. **떠 있는 유리** — 사이드바 · 작업 패널 · 툴바 캡슐 · 탭바 (+ 선택 항목은 한 겹 더 뜬 유리 방울).

유리 재료 (모든 브라우저 동일):
| 항목 | 라이트 | 다크 |
|---|---|---|
| 틴트 | 흰 26% (작업 패널 52%) | `rgba(40,42,48,.30)` (패널 .62) |
| 배경 필터 | `blur(14px) saturate(1.45) brightness(1.06)` | `… brightness(.92)` |
| 테두리 반사 | 안쪽 1px 흰 38% + 왼위 흰 95% / 오른아래 흰 55% 하이라이트 + 안쪽 광택 22px | 같은 구조, 35% / 12% |
| 반사 링 | 140° 그라데이션 1px (왼위 100% → 투명 → 오른아래 60%) | 50% / 20% |
| 그림자 | `0 8px 40px rgba(0,0,0,.12)` (Figma 값) | `.45` |

SVG 굴절(변위맵)은 Chrome 전용이고 Safari·Firefox 미지원이라 쓰지 않음.
