# 견본 (보관용)

예전에 만든 참고용 앱 모음이다. 원래는 `ohinfo/public/견본/`에 있어서
`kakainfo.com/견본/…`으로 **누구나 접근할 수 있었다.** 안에 다른 Firebase
프로젝트의 API 키가 들어있고 그 프로젝트들의 보안 규칙 상태는 이 레포에서
확인할 수 없어서, 학생 사이트의 공개 표면을 줄이려고 여기로 옮겼다.

지금 위치(레포 루트)는 Cloudflare Pages의 빌드 출력 디렉터리(`ohinfo/public`)
바깥이라 배포되지 않는다. 다시 서비스할 일이 생기면 그 전에 각 앱이 쓰는
Firebase 프로젝트의 규칙부터 점검해야 한다.
