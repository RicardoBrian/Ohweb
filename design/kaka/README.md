# kaká 디자인 시스템

원본 페이지(부품 미리보기 포함): https://claude.ai/artifact/NgyLXW5uUU3JnzENYdJQme
시제품: `prototype.html`(가짜 자료, 브라우저로 바로 열림) · https://claude.ai/artifact/Fr86uN8mv6igBNsGhoBscC

## 파일
- `ohinfo/public/kaka/kaka.css`: 토큰 + 글자 단계 + `k-` 부품. 학생 사이트는 `/kaka/kaka.css`, 관리자 사이트는 `https://kakainfo.com/kaka/kaka.css`로 불러온다.
- `ohinfo/public/kaka/logo.svg`: 색 변수로 테마를 따라가는 로고(인라인으로 넣을 때). `logo-light.svg`·`logo-dark.svg`는 `<img>`용, `favicon.svg`는 탭 아이콘.
- `design/kaka/tokens.json`: 색·글자·간격 원본. 바꾸면 `kaka.css`도 같이 고친다.
- `design/kaka/mklogo.py`: IBM Plex Mono Medium 글자를 선(패스)으로 바꿔 로고를 만드는 스크립트. fonttools와 `fonts/IBMPlexMono-Medium.ttf`(Google Fonts)가 필요하다.

부품별 쓰는 법은 원본 페이지의 각 부품 설명을 본다.

kaká는 kakainfo(관산중 정보 수업 사이트)의 화면 규칙입니다. 선생님 한 명이 수업·평가·기록을 한곳에서 하고, 학생 대부분(약 90%)은 한국어가 모국어가 아닙니다. 그래서 화면은 **단정하고 차분하게**, 글은 **짧고 번역하기 쉽게** 만듭니다. 정보 과목다운 코드 느낌은 로고와 실제 코드에만 두고, 나머지 화면은 평범한 학교 도구처럼 보이게 합니다.

## 원칙

1. **한 화면에 한 가지 일.** 주 버튼(`.k-btn--primary`)은 한 화면에 하나만 둡니다.
2. **색은 뜻이 있을 때만.** 대부분은 `ink`와 회색 단계로 만들고, 초록(`accent`)은 행동과 완료, 겨자(`warn`)는 선생님이 봐야 할 것, 벽돌(`danger`)은 잘못된 것에만 씁니다. 파란색은 쓰지 않습니다.
3. **상자는 적게, 너비는 내용만큼.** 목록·표·진행 현황은 상자로 감싸지 않고 여백과 줄로 나눕니다. 테두리 상자(`surface` + `line` + `radius-lg`)는 따로 조작하는 한 덩어리(도구 카드, 대화창)에만 씁니다. 상자와 글줄은 화면 끝까지 늘이지 않습니다: 목록 640px, 도구 카드 480px, 안내 상자 560px, 읽는 글 `reading-w`까지.
4. **양 끝으로 벌리지 않는다.** 제목은 왼쪽, 상태 칩은 오른쪽 끝에 두는 배치를 쓰지 않습니다. 칩·버튼은 설명하는 대상 바로 옆에 둡니다. 양 끝 배치는 맨 위 머리글뿐입니다. 그림자(`shadow-pop`)는 메뉴·대화창·알림처럼 떠 있는 것에만.
5. **고정폭 글자는 코드에만.** `font-mono`는 코드 블록·파일 이름에만 씁니다. 점수·학번처럼 줄을 맞출 숫자는 일반 글자에 `tabular-nums`를 줍니다. 이름표를 영어 대문자로 쓰거나 번호를 `01`처럼 0으로 채우지 않습니다.
6. **학생 화면은 한 단계 크게.** 버튼 `control-lg`, 읽는 글 `t-reading`(18px).

## 말투 (글 쓰는 법)

- 존댓말 평서문, 짧게. "제출하세요.", "저장했습니다." 느낌표와 이모지는 쓰지 않습니다.
- 버튼에는 일어날 일을 씁니다: "수업 시작", "스크래치 열기", "점수 넣기". "확인", "예"는 쓰지 않습니다.
- 학생 화면 글은 번역됩니다. 한 문장에 한 가지만 말하고, 줄임말·유행어·비유를 쓰지 않습니다. 
- 오류 글은 무엇이 틀렸고 어떻게 고치는지 씁니다. "만점이 평가계획의 산출 가능 점수(100점)보다 큽니다." 사과하지 않습니다.
- 낱말을 하나로 정해 씁니다: **과목**(1학년 정보 등), **반**, **차시**, **도구**, **제출**, **평가**, **관찰**, **세특**. "클래스", "강의", "과제물"처럼 섞지 않습니다.

## 색

- 바탕은 `bg`, 그 위 한 층은 `surface`, 눌림·마우스 올림은 `surface-2`. 셋 다 초록 기운이 아주 조금 든 회색입니다.
- 글자는 `ink`(본문), `ink-2`(보조), `ink-3`(번호·안내 글). 세 가지 모두 `bg`·`surface` 위에서 4.5:1 이상입니다. `ink-3`은 `surface-2` 위에 쓰지 않습니다.
- `accent` 위 글자는 흰색이 아니라 `on-accent`입니다(어두운 화면에서는 초록이 밝아져 어두운 글자가 됩니다).
- 상태 색은 늘 글자와 함께 씁니다: 완료 `accent-soft` + `accent-ink`, 봐야 함 `warn-soft` + `warn`, 오류 `danger-soft` + `danger`. **미제출은 `warn`입니다.** 미제출은 기본점수로 처리되는 정상 상태라 빨강을 쓰지 않습니다.
- 코드 영역은 두 화면 모두 어둡습니다: `code-bg` 위에 `code-ink`, `code-muted`, `code-key`, `code-str`.
- 키보드 포커스는 `focus`(= `accent`) 2px 실선을 2px 띄워 그립니다. 모든 바탕 위에서 3:1 이상입니다.

## 글자

- 글: IBM Plex Sans KR(한국어), IBM Plex Sans(영어·러시아어), Noto Sans SC(중국어) 순서로 이어집니다(`font-sans`).
- 코드: IBM Plex Mono(`font-mono`). 로고도 이 글꼴입니다. 코드 블록과 파일 이름 밖에서는 쓰지 않습니다.
- 크기 단계는 `t-display` 28 / `t-title` 21 / `t-heading` 17 / `t-body` 15 / `t-small` 13, 학생 읽기 `t-reading` 18, 숫자 `t-num` 14, 코드 `t-code` 14 / `t-mono-label` 12. 이 밖의 크기를 만들지 않습니다.
- 제목은 600, 본문 400, 이름표·버튼 500. 700 이상은 쓰지 않습니다.

## 간격·모서리·크기

- 간격은 `space-1` 4 · `space-2` 8 · `space-3` 12 · `space-4` 16 · `space-5` 24 · `space-6` 32 · `space-7` 48만 씁니다. 형제 요소 사이는 `gap`으로 줍니다.
- 모서리는 작게: 꼬리표·칩 `radius-sm` 4, 버튼·입력칸 `radius-md` 6, 카드·대화창 `radius-lg` 10. 둥근 알약 모양은 진행 막대와 사람 동그라미(`radius-full`)뿐입니다.
- 높이: 교사 화면 버튼·입력칸 `control` 36, 표 안 `control-sm` 28, 학생 화면 `control-lg` 44, 머리글 `header-h` 56.
- 너비: 교사 화면 본문 `content-w` 1120 안, 학생 차시 문서 `reading-w` 720 안. 폰 가장자리 `space-4`, PC 가장자리 `space-5`.

## 화면 뼈대

- **교사**: 머리글(`AppHeader`: 오늘 / 과목 / 자료실 / 도구) → 과목 안에서는 `Tabs`(수업 / 평가 / 학생 / 설정). "오늘" 화면은 지금 수업할 차시와 반을 맨 위에 보여 줍니다.
- **학생**: 머리글(오늘 차시 / 내 과목 / 기록장 + 언어) → 로그인하면 오늘 차시 문서가 바로 열립니다. 문서 안에 도구(`ToolCard`)가 흐름대로 끼어 있습니다.
- **폰(관찰 기록)**: 머리글 없이 지금 반의 `SeatGrid`가 바로 열립니다.
- **수업 화면(프로젝터)**: 같은 차시 문서를 발표 모드로 크게. 자리판·점수·학생 상태는 띄우지 않습니다.

## 상태와 움직임

- 마우스 올림: 바탕을 `surface-2`로. 누름 효과·튀는 움직임은 없습니다.
- 바뀜 시간은 0.12초 `ease-out` 하나만 씁니다. 화면 전체를 움직이는 효과는 쓰지 않습니다.
- 커서 깜빡임은 로고에만 있습니다. `prefers-reduced-motion`이면 멈춥니다.
- 비활성은 `opacity .45`와 바뀐 글자("저장됨")를 함께.

## 언어

- 언어는 넷입니다: 한국어(`ko`), 중국어(`zh`), 러시아어(`ru`), 영어(`en`). 학생 계정에 저장하고 `LangMenu`로 바꿉니다. 브라우저 번역에 기대지 않습니다.
- 러시아어·영어로 바꾸면 글이 30~50% 길어집니다. 버튼과 칩은 줄바꿈 없이 늘어나게, 고정 너비를 주지 않습니다.

## 도구 표시와 아이콘

- 도구는 이름 꼬리표(`.k-tag`)로 표시합니다: 스크래치, 파이썬, 앱 인벤터, AI 실험실, 확인 문제, 게시판, 코랩.
- 자동 확인 항목은 초록 체크와 빈 동그라미(`.k-checks`)로 씁니다.
- 꼭 아이콘이 필요하면 Lucide(선 1.5px, 18px, `currentColor`)를 쓰고, 아이콘만 두지 말고 글자를 함께 둡니다. 이모지는 쓰지 않습니다.

## 로고

- 머리글에는 `assets/Logos`의 `kaka-logo-light.svg`(밝은 화면)와 `kaka-logo-dark.svg`(어두운 화면)를 `.k-logo`로 함께 넣고, 높이 22px로 씁니다.
- 브라우저 탭과 홈 화면 아이콘은 `kaka-favicon.svg`.
- 학교 로고는 쓰지 않습니다.
