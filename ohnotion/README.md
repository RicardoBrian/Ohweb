# ohnotion — note.kakainfo.com ("정보 학습지")

학생에게 보여줄 노션 페이지를 내 도메인에서 보여 주는 사이트. 첫 화면(`/`)은 관리 페이지이고,
학생용 목록은 없다 — 학생은 선생님이 준 `/{주소}` 링크로만 들어온다.

## 왜 이렇게 만들었나 (중요)

학교에서 노션이 무한 새로고침에 빠지거나 깨지는 원인은 **노션의 요청 제한(429)** 이었다.
학교는 학생 PC 전체가 공인 IP 하나를 같이 쓰는데, 반 전체가 노션을 열면 노션이 그 IP를
"요청 과다"로 보고 CSS/JS를 거절한다(실제 콘솔: `_assets/*.js 429`, MIME `text/html`).
그래서 처음 버전처럼 iframe으로 `notion.site`를 띄우는 방식으로는 해결이 안 됐다.

지금은 **학생 브라우저가 노션에 전혀 접속하지 않는다.** Cloudflare 서버가 공식
**Notion API**로 페이지를 읽어 HTML로 그려 두고(2분마다 새로), 학생은 그것만 받는다.
학생이 몇 명이든 노션 쪽 요청은 몇 분에 몇 건이다. 노션 API가 잠깐 장애여도 마지막으로
그린 내용을 보여 준다(최대 7일).

노션에 올린 **HTML 파일**(노션은 다운로드만 시킴)도 여기서는 바로 실행된다 — 격리된
상태(CSP sandbox)로 내려 줘서 같은 도메인의 관리 페이지에 손대지 못한다.

## 주소

| 주소 | 누가 | 내용 |
|---|---|---|
| `note.kakainfo.com/` (= `/admin`) | 관리자 | 등록·수정·삭제·순서 + 모니터링 (Google 로그인) |
| `note.kakainfo.com/{주소}` | 학생 | 그 노션 페이지 |
| `note.kakainfo.com/{주소}/{페이지ID}` | 학생 | 그 안의 하위 페이지 (본문 링크로 이동) |

글꼴은 IBM Plex Sans KR / IBM Plex Mono(Google Fonts). 코드 블록은 Prism(cdnjs)으로 색칠하고,
수식은 KaTeX(jsdelivr) — 둘 다 그 블록이 있는 페이지에서만 불러온다.

## 처음 한 번: 노션 통합 연결

1. 노션 → **설정 → 연결(통합) → 통합 개발/새 통합 만들기**(내부 통합). 읽기 권한만 있으면 된다.
2. 나온 시크릿(`ntn_…`)을 Cloudflare Pages `ohnotion` → Settings → Variables and Secrets에
   **`NOTION_TOKEN`** (Secret, Production)으로 넣고 재배포.
3. 학생에게 보여줄 노션 페이지마다 오른쪽 위 **··· → 연결 → 그 통합 추가**.
   하위 페이지는 자동으로 포함된다. **연결한 페이지는 이 사이트로 누구나 볼 수 있다** —
   공개하면 안 되는 페이지에는 연결하지 않는다. "웹에 게시"는 안 해도 된다.

## 페이지 등록

`note.kakainfo.com` → Google 로그인 → 주소(`공지`), 노션 페이지 링크(공유 → 링크
복사), 제목(비우면 노션 제목) → **등록**. `notion.so`/`notion.site`/임베드 iframe 코드 모두
받는다. 링크에서 32자리 페이지 ID만 쓰므로 사이트 첫 화면 주소(`xxx.notion.site/`)는 안 된다.

노션에서 내용을 고치면 학생 화면에 **2분 안에** 반영된다. 바로 보이게 하려면 관리
페이지의 **⟳**(지금 새로 불러오기).

## 사진 크게 보기

본문 사진을 누르면 노션처럼 어두운 화면 위에 크게 뜬다(`public/lightbox.js`). 클릭·더블클릭 = 맞춤↔2배,
휠·+/- = 확대·축소, 끌기 = 옮기기, ←/→ = 같은 페이지의 다른 사진, Esc·바깥 클릭 = 닫기, ↗ = 원본 새 탭.
발표 모드에서도 되고(그 슬라이드의 사진끼리), 사진이 떠 있는 동안은 슬라이드가 넘어가지 않는다.

## 관리 페이지(kakanotion): 카테고리 · 정렬 · 비밀번호

- 목록은 **최신 등록순**(맨 위가 가장 최근). 위쪽 칩으로 **카테고리별 보기**(전체 / 각 카테고리 / 미분류), 오른쪽 칸으로 제목·주소 검색.
- **카테고리**: 등록 폼에 직접 입력하거나 "기존 카테고리 ▾"에서 골라 넣는다(입력칸에도 자동완성). 비우면 미분류.
- **비밀번호(선택)**: 정하면 학생이 그 주소(하위 페이지 포함)를 열 때 비밀번호를 묻는다. 맞히면 그 브라우저에서 12시간 동안 다시 안 묻는다.
  비밀번호를 바꾸면 이미 들어온 사람도 다시 입력해야 한다. 칸을 비우고 저장하면 잠금 해제. 수정 화면에서 지금 비밀번호가 보인다.
  - 저장 위치: `notion_pages`에는 `locked: true`만(공개 읽기라서), 비밀번호는 관리자 전용 `notion_secrets/{주소}`.
    학생 화면은 서비스 계정으로 확인한다(`lib/lock.js`) — **`FIREBASE_SERVICE_ACCOUNT_KEY`가 없으면 잠긴 페이지는 열리지 않는다.**
  - 잠금/해제는 학생 화면에 최대 2분 뒤 반영(페이지 정보 캐시). 한계: 사진·파일 주소(`/api/file?b=…`)는 블록 ID를 알면 열린다.

## 발표 모드 (노션 유료 프레젠테이션 대신)

페이지 상단 **▶ 발표**(또는 관리 페이지 목록의 ▶, 주소 끝에 `#present` / `#present=3`)로
그 노션 페이지를 16:9 슬라이드로 보여 준다(`public/present.js`).

- 나누는 규칙: **구분선(---)마다**, 그리고 **제목 1마다**(2개 이상일 때 — 아니면 제목 2마다).
- 맨 앞 표지에는 학생이 보고 들어올 **`note.kakainfo.com/주소`를 화면 폭 가득** 띄운다(위에 페이지 제목은 작게).
  주소는 항상 한 줄(길면 글씨가 작아짐 — 주소는 짧게 짓는 게 좋다). 하위 페이지에서 발표해도 첫 주소를 보여 준다.
- 슬라이드에서 토글을 펼치면 그 장을 다시 맞춘다(조금 넘치면 글씨를 줄이고, 많이 넘치면 장 안에서 스크롤).
- 조작: → / Space / PageDown = 다음, ← / PageUp = 이전, Home·End, F 전체 화면, B 화면 가리기, Esc 끝내기,
  화면 왼쪽 1/3 클릭 = 이전·나머지 = 다음, 휴대폰은 스와이프. 발표 리모컨(클리커)도 그대로 된다.
- 내용이 넘치면 그 슬라이드만 자동으로 줄이고(최대 55%), 그보다 많으면 슬라이드 안에서 스크롤.
- 노션에서 고친 내용은 2분 안에 발표 화면에도 반영된다(새로고침).

### 학생 화면 고정(따라가기)

관리 페이지에 로그인한 브라우저에서 발표하면, 발표 화면 오른쪽 아래 조작 줄에 **👥** 버튼이 생긴다(단축키 **L**).
누르면 🔒로 바뀌고 왼쪽 위에 "학생 화면 고정 중"이 뜬다.

- 그 학습지 주소를 열어 둔 학생 화면은 저절로 발표 모드가 되어 **선생님이 넘기는 슬라이드만** 보인다.
  학생은 넘기기·끝내기가 다 막힌다(전체 화면 F만 됨). 늦게 들어온 학생도 들어오자마자 같은 장으로 맞춰진다.
  선생님이 하위 페이지에서 발표하면 학생도 그 페이지로 옮겨 간다. 화면 가리기(B)도 학생에게 똑같이 된다.
- 고정 중에 슬라이드 안의 하위 페이지 링크를 누르면 **고정·발표가 풀리지 않고** 그 페이지의 첫 장부터 이어진다.
  같은 탭에서 새로고침·뒤로 가기를 해도 1분 안이면 발표·고정이 다시 켜진다.
- 다시 누르거나(L) 발표를 끝내면(Esc·✕) 풀린다. 학생은 보던 장에서 마음대로 넘기거나 끌 수 있다.
- 선생님이 탭을 그냥 닫으면 학생은 **5분 뒤** 저절로 풀린다(켜 둔 동안 2분마다 신호를 보냄).
- 학생이 다른 탭을 보고 있으면 브라우저가 그 탭의 연결을 늦추거나 끊어 "풀림"을 놓칠 수 있다 — 그 탭으로 돌아오면
  서버에서 지금 상태를 바로 다시 읽는다. 학생이 스스로 푸는 버튼은 없다(일부러 뺐다).
- 선생님의 👥/🔒 는 저장된 상태를 따른다. 다른 창·이전 페이지에서 켠 고정이 남아 있으면 🔒(왼쪽 위 "다른 창에서 켠
  학생 고정이 남아 있어요")로 보이고, 누르면 푼다.
  선생님이 풀었는데 학생이 안 풀리면 먼저 **다른 컴퓨터·다른 창에 켜 둔 발표가 없는지** 본다. 두 창에서 켜면 나중에 켠 창이 이기고 먼저 켠 창은 신호를 멈춘다.
- 구조: `public/follow.js`. 상태는 `appSettings/ohnotion_follow_{주소}` = `{ on, path, slide, total, blank, at }`
  (규칙상 공개 읽기·관리자 쓰기 — 규칙 변경 없음). 학생 화면은 Firestore를 직접 듣는다(onSnapshot) —
  슬라이드를 넘길 때마다 학생 1명당 읽기 1번이고, Cloudflare 요청은 늘지 않는다.
- 선생님 판별: 관리 페이지에서 로그인하면 그 브라우저에 `kakanotion-teacher` 표시가 남고(로그아웃하면 지움),
  관리자 계정으로 로그인돼 있을 때만 버튼이 보인다. 쓰기는 Firestore 규칙이 다시 막는다.

### 발표 필기

관리 페이지에 로그인한 브라우저(선생님)의 발표 화면에만 **✏️**(단축키 **D**)가 있다. 따라가기 중인 학생 화면에 같이 보인다.

- 색: **1** 검정 · **2** 빨강 · **3** 파랑 · **4** 형광 노랑 · **5** 형광 분홍 · **6** 형광 하늘. **Z** = 이 장 마지막 획 지우기, 🗑 = 이 장 다 지우기,
  **Esc** = 필기 끄기(한 번 더 Esc 면 발표 끝). 필기 중에는 클릭·스와이프로 장이 안 넘어간다(→ 키는 됨). 표지에는 못 쓴다.
- **태블릿**: 필기 중 **펜·한 손가락은 쓰기, 두세 손가락은 위아래로 끌면 스크롤·옆으로 쓸면 장 넘기기**.
  한 손가락으로 쓰기 시작한 직후 두 번째 손가락이 닿으면 그 획은 버리고 스크롤로 바뀐다.
  펜으로 쓰는 중이거나 막 뗀 직후의 손가락(손바닥)은 무시한다. 마우스는 늘 쓰기.
- 획은 손을 뗄 때 저장돼 학생 화면에 나타난다(그리는 도중 모습은 안 보냄). **장마다 남고, 발표를 끝내면 다 지운다.**
  같은 탭에서 새로고침하면 이어지고, 하위 페이지로 가면 그 페이지는 빈 상태로 시작한다.
- 필기는 화면 좌표가 아니라 **그 장의 몇 번째 블록(문단·그림·표…) 안의 위치**로 저장한다. 그래서 스크롤해도 내용에 붙어 있고,
  다국어 학생에게는 자기 언어 슬라이드의 같은 번째 블록 위에 그려진다(글 길이가 달라 블록 안의 정확한 자리는 어긋날 수 있음 —
  그림·표 위 필기는 거의 그대로). 블록 수가 한국어와 다른 장은 그 언어 학생에게 필기를 안 보인다.
- **스크롤 따라가기**: 선생님이 긴 장을 스크롤하면 학생 화면도 같은 블록으로 맞춰진다(다국어도 블록 기준). 학생도 스스로
  스크롤할 수 있고, 선생님이 다시 스크롤하면 그 위치로 맞춰진다.
- 구조: `public/ink.js`. 상태는 `appSettings/ohnotion_ink_{주소}` = `{ path, slides: { 장: [획] }, scroll, at }`(규칙 변경 없음).
  획 하나 = 쓰기 1번, 학생 1명당 읽기 1번. 문서 하나 1MB 한도라 한 발표에 획 수백~천 개 정도까지.

## 다국어 학습지 (언어별 노션 페이지)

따로 등록하지 않는다. 한국어 본 페이지 **안에 하위 페이지**로 언어 페이지를 만들면 서버가 제목으로 알아본다
(`lib/notion.js` `langOfTitle`, 본 페이지를 그릴 때 `data.langPages`에 담긴다).

- 제목 앞에 `[en] 제목` 처럼 코드를 붙인다(`en zh ru vi ja uz mn kk ky th tl km ne id ar es fr de`, `[zh-TW]` 도 됨).
- 코드가 없어도 제목이 중국어(한자)·러시아어(키릴)·일본어(가나)·태국어·크메르어·아랍어·네팔어 글자면 그 언어로 본다.
  영어 같은 로마자는 코드가 있어야 한다. 한글이 섞인 제목은 언어 페이지로 보지 않는다.
- 언어 페이지는 본문에 링크로 그리지 않고, 앞의 `🌐 …`(12자 이하) 안내 줄도 같이 뺀다. 화면 제목의 `[en]` 도 뺀다.
- 예전에 관리 폼에서 등록한 언어(`appSettings`의 `langs`)는 그대로 읽는다(같은 코드면 그쪽이 우선). 폼의 입력란은 없앴다.
  목록의 `🌐 N개 언어` 표시는 이 예전 등록분만 센다.

- 학생이 그 주소를 탭에서 처음 열면 **언어부터 골라야** 내용이 보인다(가리개를 닫을 수 없음).
  학교 PC는 여러 학생이 같이 쓰므로 고른 언어는 **그 탭에만** 기억한다 — 다음 학생이 새로 열면 다시 묻는다.
  위쪽 **🌐** 버튼으로 언제든 바꿀 수 있다. 선생님 브라우저(관리 페이지에 로그인한 곳)는 묻지 않는다.
- 주소는 `/{주소}?lang=en` — 서버가 그 언어 페이지를 그린다. 이 링크를 직접 주면 고르지 않고 바로 그 언어로 열린다.
  없는 언어 코드면 한국어. 하위 페이지(`/{주소}/{ID}`)는 ID가 이미 그 언어 페이지 안의 것이라 그대로 열린다.
- **발표 따라가기와 같이 쓰기**: 선생님은 한국어 페이지로 발표하고, 학생은 고른 언어 페이지에서 **같은 장 번호**로
  따라간다. 그래서 언어별 페이지의 구분선(---)·제목 1 구성을 똑같이 맞춰야 장이 맞는다. 발표 중에 들어와
  아직 언어를 안 고른 학생은 발표 화면 위에 언어 고르기가 먼저 뜨고, 고르면 그 언어로 같은 장에 붙는다.
  선생님이 고정 중에 하위 페이지 링크를 누르면, 학생은 **자기 언어 페이지에서 같은 번째 하위 페이지 링크**로 옮겨 간다
  (그래서 언어별 페이지의 하위 페이지 순서도 똑같이 맞춘다). 선생님이 이미 하위 페이지에 있을 때 새로 들어온 학생은
  어느 언어 페이지인지 알 수 없어 한국어 하위 페이지로 간다.
- 예전 등록분 저장 위치: `appSettings/ohnotion_site.langs.{주소}` = `[{ code, url, pageId }]` — `notion_pages` 규칙은 필드를
  제한하므로 규칙을 고치지 않으려고 여기에 뒀다. 서버는 숨김 목록과 같은 문서를 15초 캐시로 읽으므로 Firestore 읽기가 늘지 않는다.
  바꾼 내용은 학생 화면에 최대 15초 뒤 반영.
- 언어 목록은 `lib/notion.js`의 `LANG_CODES`, `public/admin.js`의 `LANGS`, `public/lang.js`의 `NAMES`(셋을 같게).

## 페이지 숨기기 (시험 기간)

관리 페이지 목록에서 페이지마다 **⏸**(숨기기) / **👁**(다시 공개). 지우지 않고, 숨긴 동안 그 주소(하위 페이지 포함)만
"지금은 열 수 없어요" 화면으로 바뀐다. 다른 페이지는 그대로 열린다.

- 이미 열려 있던 학생 화면은 30초마다 `/api/status?slug=…`를 물어 **스스로 새로고침**해 닫힌다(탭으로 돌아오면 바로 확인).
  서버는 숨김 목록을 15초 캐싱하므로 누른 뒤 **최대 1분 안에** 닫힌다. 다시 공개도 같은 방식으로 저절로 열린다.
- 저장 위치: `appSettings/ohnotion_site.closedSlugs` (주소 배열 — 규칙상 공개 읽기·관리자 쓰기, 규칙 변경 없음).
- 한계: 사진·파일 주소(`/api/file?b=…`)는 막지 않는다(블록 ID만으로는 어느 페이지인지 몰라서).

## 모니터링

- **점검**(`/api/check`) — 노션 API로 그 페이지가 읽히는지(토큰·통합 연결). ⟳는 전체를 새로 그림.
- **학생 기록**(`notion_stats`, 오늘 / 최근 7일)
  | 기록 | 뜻 |
  |---|---|
  | 열람 | 연 횟수(탭당 1번) |
  | 이상해요 신고 | 학생이 상단 버튼을 누름 |
  | 예전 내용으로 대신 | 노션 API 장애로 마지막 저장본을 보여 줌 |
  | 불러오기 실패 | 저장본도 없어 못 보여 줌 |
  slow/timeout/loop(옛)는 iframe 방식이던 첫 버전의 기록이다.

## 구조

```
functions/
  [[slug]].js        목록 / 페이지 / 하위 페이지 (Notion API → HTML)
  api/check.js       점검 · 지금 새로 불러오기
  api/file.js        노션 이미지·파일·HTML을 우리 도메인으로(서명 주소 갱신, HTML은 격리)
  api/report.js      학생 기록 +1
  api/status.js      그 주소가 숨겨졌는지(학생 화면이 30초마다 물음)
lib/                 (functions/ 밖이라 라우트가 아님)
  notion.js          Notion API 클라이언트(동시 3건, 429 재시도) + 블록 → HTML
  render.js          캐시: 신선본 2분 / 예비본 7일, 같은 페이지 동시 그리기 합치기
  shared.js          주소 규칙, Firestore REST, 통계 기록
public/
  view.js, view.css  학생 화면(노션 요청 없음, 웹 폰트도 없음)
  present.js         발표 모드(window.KakaPresent)
  follow.js          발표 따라가기 — 학생 화면 고정(Firestore onSnapshot)
  ink.js             발표 필기·스크롤 따라가기(선생님 쓰기 → 따라가는 학생에게)
  lang.js            다국어 학습지 — 언어 고르기
  admin.html/js/css  관리 페이지
```

Firestore (규칙은 레포 루트 `ohweb-firestore.rules`):

- `notion_pages/{주소}` — `title`, `url`, `pageId`, `order`, `hidden`, `createdAt`, `updatedAt`. 읽기 공개, 쓰기 관리자.
- `notion_stats/{YYYY-MM-DD}_{주소}` — 결과별 카운터 + `lastAt`. 읽기 관리자, 쓰기는 서버(서비스 계정)만.

## 한계

- 노션의 모든 블록을 똑같이 그리지는 못한다. 글·제목(토글 제목)·목록(1.→a.→i.)·할 일·토글·
  인용·콜아웃(배경색/테두리)·코드(언어 표시·색칠·복사)·수식·구분선·이미지·동영상·오디오·파일·PDF·
  임베드(유튜브·구글 슬라이드/문서/시트/설문/드라이브·Figma·CodePen·Loom·Canva는 임베드 주소로)·
  북마크 카드(제목·설명·대표 이미지)·표·열·동기화 블록·하위 페이지·페이지 링크·목차·멘션·
  데이터베이스(표 하나 — 제목 + 속성 5개)를 그린다. 데이터베이스의 보드/캘린더 보기, 버튼 블록은 안 된다.
- Cloudflare 무료 플랜은 요청 하나당 외부 호출(subrequest)이 50번까지다. 열·표·토글이 많은 큰 페이지는 한 번에
  다 못 읽어서(502), 한 요청에서 노션 호출을 20번(`CALL_BUDGET`)까지만 쓰고 다 못 읽으면 읽은 데까지
  저장(`partial:{페이지ID}`, 2분)한 뒤 "불러오는 중" 화면이 1초 뒤 스스로 새로고침해 이어 읽는다.
  한 번 완성되면 그다음은 저장본으로 바로 열린다. 관리 페이지 ⟳도 "나눠 불러오는 중"이면 한 번 더 누르면 된다.
- 요청당 CPU 시간도 짧다. 아주 큰 페이지(블록 수천 개)는 하위 페이지로 나눈다.
