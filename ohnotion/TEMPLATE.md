# 노션 페이지 작성 규칙

note.kakainfo.com 으로 학생에게 보여 줄 노션 페이지를 쓸 때의 규칙. 스킬 `/notion-worksheet` 가 이 문서를 따른다.
사이트가 그리는 방식은 `README.md` 참고.

## 공통 규칙

**문체**
- 학생용은 "~다" 체. 느낌표, "~해보자!" 같은 권유는 줄인다.
- 쓰지 않는 표현: "한 줄 아이디어" 같은 고정 틀, 비유 남발, "오늘은 ~를 알아본다" 식 도입, 끝에 앞 내용을 다시 요약하는 문단.

**링크**
- 이동/열기 링크는 **파랑 칸(아이콘 👉) 안에 제목 3 링크**로 쓴다. 링크 글자는 `제목 열기`. "누르기"는 쓰지 않는다.
- 문장 속 링크는 링크 글자를 그 페이지의 제목이나 하는 일로 쓴다. 주소를 글자로 쓰지 않는다 (`kakainfo.com` ✕).
- 주소는 https. 같은 링크를 한 페이지에 여러 번 넣지 않는다.
- 다운로드는 초록 칸 안에 제목 3 링크. 글자는 파일명과 확장자 (`tick.wav`).
- 언어 페이지는 링크 목록을 따로 쓰지 않는다. 본 페이지 안에 하위 페이지로만 둔다 (아래 사이트 제약).

**칸(callout) 색 — 뜻을 고정한다**
| 색 | 뜻 | 아이콘 |
|---|---|---|
| 파랑 | 이동/열기 | 👉 |
| 초록 | 다운로드, 실험 | 📥 🧪 |
| 노랑 | 주의 | ⚠️ |
| 회색 | 예시, 생각해보기 | ✏️ 🤔 |
| 보라 | 다음 시간 | ➡️ |
| 색 없음 | 학습 목표, 한눈에 보기 | 🎯 |
- 반 구분 칸은 2-1 빨강, 2-2 주황, 2-3 초록, 2-4 파랑, 2-5 보라 (🔴🟠🟢🔵🟣).

**구성**
- `따라 풀기`, `확인 문제`, `1단계` 같은 소제목은 굵은 글씨가 아니라 **제목 3**으로 쓴다.
- 사진은 칸에 싸지 않는다. 설명이 필요하면 캡션만 붙인다. (이미 칸에 싸인 기존 사진은 노션 연동으로 풀 수 없어서 그대로 둔다.)
- 빈 블록으로 간격을 띄우지 않는다.
- 페이지 아이콘은 주제에 맞는 걸 하나 쓴다 (카테고리별로 통일하지 않는다). 기존 아이콘이 있으면 바꾸지 않는다. 본문에 장식 이모지는 쓰지 않는다 (칸 아이콘 제외).
- 날짜가 필요한 제목은 `11/4 ...` 처럼 앞에 둔다.
- 힌트는 토글 `힌트`. 정답은 페이지에 넣지 않는다 (필요하다고 하면 `정답` 토글을 따로).

**사이트 제약**
- 발표 모드는 `---` 와 제목 1 로 장을 나눈다. 장 하나에 핵심 하나. 중요한 내용은 토글 안에 넣지 않는다.
- 페이지가 길면 하위 페이지로 나눈다. 큰 페이지는 한 번에 못 읽는다.
- 목차 블록은 쓰지 않는다 (소제목까지 전부 나열해서 첫 화면을 차지한다).
- 못 그리는 것: 데이터베이스의 보드/캘린더 보기, 버튼 블록. 쓰지 않는다.
- 표는 3열까지. 그 이상은 폰에서 좁아진다.
- 다국어 버전은 한국어 본 페이지 안의 하위 페이지로 만들고 제목 앞에 `[en]` 처럼 코드를 붙인다 (사이트가 자동으로 언어 고르기에 넣는다. 관리 화면에 따로 등록하지 않는다). `---` 와 제목 1 구성은 한국어와 똑같이 맞춘다.

**순서도**
- 순서도는 `tools/flowchart/` 도구로 만든 HTML 을 첨부한다. 규칙(도형 4가지, 서랍 색 글자, 이벤트당 한 장, 언어별 파일)은 `tools/flowchart/README.md`.
- 다국어 페이지는 언어마다 그 언어 순서도를 붙인다. 한 순서도에 여러 언어를 섞지 않는다.
- 페이지에서는 `## 순서도` 제목 → 한 줄 설명 → 첨부 순서.

## 카테고리별 양식

### 1. 개념 학습지
1. 학습 목표 — 🎯 칸, 목록 3개 이내
2. 활동 N — 제목 1. 설명 → `따라 풀기` (제목 3) → `확인 문제` (제목 3, 힌트 토글)
3. 정리 — 제목 1, 표
4. 다음 시간 — 보라 칸 (선택)

### 2. 실습/앱 만들기
1. 목표 — 🎯 칸, 한 줄
2. 준비 — 로그인, 파일 받기. 파랑/초록 버튼 칸
3. 단계 — 제목 1 마다 한 단계. 번호 목록 + 사진
4. 테스트 — 체크리스트
5. 더 해보기 — 토글
6. 막힐 때 — 노랑 칸

### 3. 수행평가 안내
1. 한눈에 보기 — 🎯 칸 (일시, 범위, 문항, 응시)
2. 응시 방법 — 번호 목록 + 접속 버튼 칸
3. 범위 — 바로가기 버튼 칸
4. 문항 구성 — 표, 유형별 설명
5. 채점 기준 — 표
6. 기본점수 처리 사유 — 노랑 칸

### 4. 허브/목차
1. 한 줄 소개
2. 하위 페이지 링크 — 번호 + 제목 + 한 줄 설명. 최신/중요 항목을 위로.

### 5. 연수 자료
1. 한눈에 보기 — 🎯 칸 (대상, 일시, 목적)
2. 순서별 자료 링크
3. 참고 링크
