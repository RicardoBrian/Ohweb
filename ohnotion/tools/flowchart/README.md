# 순서도 도구

단계 목록(JSON)을 주면 순서도 HTML 을 만든다. 언어마다 파일이 하나씩 나온다.
노션 페이지에는 이 HTML 을 첨부하면 되고, 사이트(note.kakainfo.com)가 그대로 실행해서 보여 준다.

```bash
python3 flowchart.py bomb.json -o out/              # spec 의 langs 전부
python3 flowchart.py demo.json -o out/ --lang en    # 한 언어만
```

예제: `bomb.json`(앱인벤터, 한국어), `demo.json`(스크래치, 반복·분기, 한국어+영어).
글자가 상자 밖으로 넘칠 것 같으면 `주의:` 로 알려 준다. 그 줄을 나눈다.

## 작성 규칙

**도형은 네 가지만 쓴다**
| 도형 | 쓰는 곳 |
|---|---|
| 터미널 | 시작(이벤트 블록), 끝 |
| 처리 | 값 정하기, 계산, 속성 바꾸기 |
| 판단 | 예/아니오로 갈라지는 곳 |
| 입출력 | 화면, 소리, 진동, 입력(터치·센서) |

**색**
- 상자 안 블록 이름의 글자 색은 그 블록이 들어 있는 서랍 색이다. 앱인벤터는 `ai.*`, 스크래치는 `sc.*`.
- 한 순서도에 두 도구를 섞지 않는다.
- 쓰인 도형과 서랍 색 범례가 맨 위에 자동으로 붙는다.

**구성**
- 이벤트 하나가 순서도 하나다. 시작은 이벤트 블록(터미널), 끝은 `끝` + 한 줄. 사이는 점선 상자(`group`)로 묶는다.
- 상자 하나에 블록 하나(2줄까지). 아래 회색 설명은 한 줄, 짧게.
- 순서도 한 장은 상자 10개 안팎까지. 넘으면 이벤트나 단계로 나눠 장을 늘린다.
- 블록 이름은 학생 화면에 보이는 그대로 쓴다. 설명은 짧은 명사형이나 "~다" 한 줄.

**분기와 반복**
- 판단 하나에 예/아니오. 분기 안 상자는 한쪽에 3개까지.
- 반복은 "조건이 참인 동안" 방식이다. 조건 판단 → 예 → 본문 → 되돌아감, 아니오 → 빠져나감.
- 분기나 반복 안에는 처리/입출력만 넣는다. 반복 안에 분기가 필요하면 순서도를 둘로 나눈다.
- 무한 반복(forever)은 판단 없이, `무한 반복` 터미널로 시작하는 별도 순서도로 그리고 끝에 "처음으로 돌아가 계속"이라고 적는다.

**언어별**
- 한 순서도에 여러 언어를 넣지 않는다. 언어 페이지마다 그 언어 파일을 붙인다 (`이름_ko.html`, `이름_en.html`).
- 단계 수와 순서는 모든 언어에서 같다. 블록 이름은 그 언어 화면에서 보이는 이름으로 쓴다.
- 번역은 JSON 안에 언어별로 적는다. 번역이 빠지면 도구가 어느 칸인지 알려 주고 멈춘다.
- 언어 이름표(`ko` `en` `zh` `ru`)만 범례 글자를 갖고 있다. 다른 언어는 영어로 나온다.

**노션에 넣기**
- 페이지에서 `## 순서도` 제목 → 한 줄 설명 → 파일 첨부(임베드) 순서로 둔다.
- 노션은 HTML 파일을 다운로드로만 열어서, 사이트 화면에서만 순서도가 보인다.

## JSON 형식

```json
{
  "id": "파일이름",
  "langs": ["ko", "en"],
  "title": {"ko": "…", "en": "…"},
  "note":  {"ko": "…"},                       // 선택. 범례 아래 설명
  "legend": {"term": {"ko": "…"}},            // 선택. 도형 설명 바꾸기 (term/proc/dec/io)
  "charts": [{
    "title": {"ko": "① …"},
    "group": {"ko": "언제 …"},                // 선택. 처음·끝이 terminal 일 때
    "steps": [ ...단계... ]
  }]
}
```

글자는 `"문자열"`(모든 언어 같음) 또는 `{"ko": "…", "en": "…"}` 로 쓴다.

**단계**
```json
{"type": "terminal|process|io", "lines": [[["ai.set", "지정하기 시계1.타이머간격"], "값 ←"]], "desc": "설명", "w": 300}
```
- `lines` 는 줄의 목록. 줄은 조각의 목록이고, 조각은 `"그냥 글자"` 또는 `["서랍", "글자"]`.
- 줄 전체를 언어별로 줄 수도 있다: `"lines": {"ko": [...], "en": [...]}`.
- `w` 는 상자 폭(기본 터미널 280, 나머지 500). 긴 이벤트 이름에만 쓴다.

```json
{"type": "decision", "lines": [...], "yes": [단계…], "no": [단계…]}     // 한쪽은 비워도 된다
{"type": "loop", "lines": [조건…], "body": [단계…]}
```

**서랍 이름**
- 앱인벤터: `ai.ctrl` `ai.logic` `ai.math` `ai.text` `ai.color` `ai.list` `ai.var` `ai.set`(컴포넌트 속성) `ai.call`(컴포넌트 호출)
- 스크래치: `sc.motion` `sc.looks` `sc.sound` `sc.events` `sc.control` `sc.sensing` `sc.operators` `sc.vars` `sc.myblocks`
