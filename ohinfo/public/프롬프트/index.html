이 웹앱을 만드는 목적이 무엇인가요?

하나만 선택해주세요. 선택에 따라 프롬프트에 안내 문구가 자동으로 들어갑니다.

목적을 하나 선택해주세요.

앱 주제와 기능을 알려주세요

앱 주제를 입력해주세요.

최소 1개 이상의 기능이 필요합니다.

기능을 최소 1개 이상 추가하고, 기능 이름을 입력해주세요.

데이터는 어디에 저장할까요?

하나만 선택해주세요. 선택에 따라 프롬프트에 연동 방법 설명 요청이 자동으로 들어갑니다.

데이터 저장 방식을 하나 선택해주세요.

사진·PDF 파일을 저장하려면 위에서 구글 시트 연동을 골라주세요.

학생이 입력하고 선생님이 모아서 본다면 관리 페이지가 필요합니다. 관리 페이지는 쓰는 화면과 따로 만들고, 관리자만 들어갈 수 있게 합니다.

디자인은 어떻게 할까요?

디자인 내용을 입력하거나 견본을 선택해주세요.

완성된 프롬프트

아래 내용을 복사해서 Google AI Studio(Gemini)에 그대로 붙여넣으세요.

Gemini가 만든 앱을 써보고 고치거나 더하고 싶은 게 있다면, 여기서 이어서 수정 요청 프롬프트를 만들 수 있습니다.

웹앱 수정하기

추가/수정하고 싶은 내용을 정리하면, 이어서 붙여넣을 수정 요청 프롬프트를 만들어드립니다.

추가/수정할 기능, 버그, 디자인 중 최소 하나는 입력해주세요.
