# AI 실험실 — 처음 설정하기

AI 실험실(`ailab.html` 학생 화면, `aiapp.html` 공개 웹앱, 관리자 → AI 실험실)을 쓰려면
아래 순서대로 한 번만 설정하면 된다. 1~3번은 수업 전에 반드시 해야 한다.

## 1. Firestore 보안 규칙 붙여넣기

`ohweb-firestore.rules`에 AI 실험실 규칙(`ai_assignments`, `ai_pairs`, `ai_projects`, `ai_apps`)이
추가됐다. 이 규칙이 없으면 학생 화면이 "권한 없음"으로 멈춘다.

```
cd ohweb-rules-test
npm install
npm test          # "전부 통과" 확인
```

통과하면 `ohweb-firestore.rules` 전체를 Firebase 콘솔 → Firestore → 규칙에 붙여넣고 게시한다.

## 2. 사진 저장용 Apps Script 배포 (선생님 구글 드라이브)

1. <https://script.google.com> → **새 프로젝트**. 이름은 예: `AI실험실 사진 저장`.
2. 기본 `Code.gs` 내용을 지우고 이 폴더의 `ailab-drive.gs`를 통째로 붙여넣고 저장한다.
3. 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱**.
   - 설명: 아무거나
   - **다음 사용자 인증 정보로 실행: 나(선생님 계정)**
   - **액세스 권한이 있는 사용자: 모든 사용자**
4. **배포** → 권한 승인(드라이브, 외부 서비스 연결). "확인되지 않은 앱" 경고가 나오면
   고급 → 이동을 눌러 승인한다(내가 만든 스크립트라 괜찮다).
5. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사한다.
6. `ohinfo/public/ai-config.js`의 `AILAB_GAS_URL = ''` 따옴표 안에 붙여넣고 커밋·배포한다.

확인: 브라우저에서 웹 앱 URL을 열어 `{"ok":true,"app":"ailab-drive"}`가 보이면 된다.

- 사진은 `내 드라이브/AI실험실/학교 학년 반/N짝 (이름들) N번째 모델 [ID]/1_레이블/`에 쌓인다.
- 학생이 실험실에서 학습한 모델은 같은 폴더의 `models/v1`, `v2` …에 저장된다(모델 하나 약 2~3MB).
  공개 웹앱은 학생이 [공개하기]를 누른 번호의 모델만 이 스크립트를 거쳐 불러온다.
- 학생 사진은 넣는 순간 긴 변 768px JPG(품질 90%)로 줄여서 올라온다(장당 약 85KB). 한 반 전체가 약 80MB.
- 스크립트 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**로 다시 배포해야 반영된다(URL은 그대로).
- 붙여넣기가 중간에 잘리면(긴 코드) 코드를 여러 `.gs` 파일로 나눠 넣어도 된다 — Apps Script는 한 프로젝트의
  파일들을 하나로 합쳐 실행한다. `// ──` 줄(구역 머리)에서 나누면 된다.
- 사진을 올릴 때 학생의 로그인 토큰으로 "그 짝의 학생인지"를 Firestore에서 확인한다.
  그래서 주소가 알려져도 다른 사람은 드라이브에 올릴 수 없다.

## 3. 번역 키 확인 (Cloudflare)

레이블 이름과 직접 쓴 결과 문구를 중국어·러시아어·영어로 바꾸는 데 `/api/translate`를 쓴다.
ohinfo Pages 프로젝트의 환경변수 `GOOGLE_TRANSLATE_KEY`가 이미 있으면(ohdlet 번역이 되면) 따로 할 일은 없다.
없으면 번역 없이 원래 이름으로 보인다(멈추지는 않는다).

## 4. 수업 배정 (관리자 화면)

1. 관리자 → 메뉴 → **AI 실험실** → **배정 관리**: 제목, 학교·학년·반, 레이블당 최소 사진 수,
   ohdlet 게시판(학생이 웹앱을 올릴 곳)을 정하고 **배정하기**.
2. **짝 구성**: [남은 학생 번호순으로 2명씩 짝짓기] 또는 학생을 골라 [짝 만들기].
   ★를 눌러 대표(문제 정의·학습 담당)를 정한다. 결석생은 ×로 빼고 혼자 남은 학생은 1명 짝으로.
3. 관리자 → **앱 설정**에서 그 반의 **AI 실험실**을 켜면 학생 홈 화면에 카드가 생긴다.
4. 수업 중에는 **현황판**을 띄워 둔다(전체 화면 버튼). 노란 카드는 사진이 절반도 안 모인 짝이다.
5. 수업 뒤 **결과 조회**에서 짝별 기록을 보고 CSV로 내려받는다. 이상한 번역은 [고치기],
   부적절한 직접 쓴 문구는 [숨기기]로 기본 문구로 바꾼다.

## 5. 수업 전 점검(교실 PC로)

- [ ] 학생 계정으로 AI 실험실이 열리는가(배정·짝·앱 설정)
- [ ] 사진 붙여넣기(구글 이미지 → 오른쪽 클릭 → 이미지 복사 → Ctrl+V)가 되는가
- [ ] 화면 아래 "저장 대기"가 사라지고 드라이브에 사진이 생기는가
- [ ] ③ 학습에서 대표가 [학습 시작] → 진행 막대 → "1번 모델을 만들었어요"까지 되는가
      (안 되면: 학교망이 `storage.googleapis.com`(기본 모델 MobileNet)을 막는지, PC 브라우저가 WebGL을 쓰는지 확인)
- [ ] 드라이브 프로젝트 폴더에 `models/v1`이 생기는가
- [ ] ④ 평가 → 사진 보충 → ③ [다시 학습] → ④ [다시 평가하기]가 이어지는가
- [ ] 공개 웹앱 주소가 로그인 없이 열리는가

> 학교 PC에 재부팅 복원 프로그램이 있으면 브라우저에 남은(아직 저장 안 된) 사진은 사라진다.
> 수업 끝나기 전에 화면 아래 "저장 대기"가 없는지 확인하게 안내한다.
