# kaká 스크래치 — 저장소(선생님 구글 드라이브) 연결하기

학생 스크래치 파일(.sb3)은 선생님 드라이브 **kaká 스크래치** 폴더에 쌓인다. 사이트(Firestore)에는 파일 ID와 저장 기록만 남는다.
한 번만 하면 된다. 설계: `PLATFORM-DESIGN.md` §8.10

1. <https://script.google.com> → **새 프로젝트**. 이름 예: `kaká 스크래치 저장`.
2. 기본 `Code.gs` 내용을 지우고 이 폴더의 `scratch-drive.gs`를 통째로 붙여넣고 저장.
3. **배포 → 새 배포** → 유형 **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나(선생님 계정)**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** → 권한 승인(드라이브). "확인되지 않은 앱" 경고는 고급 → 이동.
5. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을
   <https://admin.kakainfo.com/k/settings.html> 에 붙여넣고 **[연결]**.
   - 화면이 비밀값을 만들어 스크립트에 한 번 등록하고, 시험 파일을 저장·불러오기·삭제해 본 뒤 연결을 마친다.

## 다시 연결하기

비밀값은 스크립트 속성 `SECRET`에 한 번만 등록된다(남이 URL을 알아도 바꿀 수 없게).
다시 연결하려면 Apps Script 편집기 → 프로젝트 설정 → 스크립트 속성에서 `SECRET`을 지우고 설정 화면에서 [다시 연결].

## 스크립트를 고쳤을 때

`scratch-drive.gs`를 바꾸면 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**. URL은 그대로라 다시 연결할 필요 없다.

## 한도

- 동시 실행 30개. 넘으면 잠시 실패 — 학생 화면은 "저장 실패"를 띄우고 다음 자동 저장(30초)에 다시 한다.
- 하루 실행 시간: 무료 계정 90분, Google Workspace 6시간. 자동 저장은 바뀐 게 있을 때만 한다.
- 파일 하나 15MB까지(서버에서 자름).
