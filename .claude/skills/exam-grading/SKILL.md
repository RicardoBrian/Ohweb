# 시험 채점 (kakainfo 시험 → 선생님 기준으로 채점 → DB 반영)

선생님이 채점 기준(평가계획)을 주면, 학생 답안을 그 기준대로 채점하고 검토를 거쳐 DB 에 쓴다.
도구: `tools/exam-grading/` (README 참고). DB 는 운영 Firebase `ohweb-93062` — 이 컴퓨터의 firebase CLI 로그인으로 접근하며 **보안 규칙을 거치지 않는다.**

## 지켜야 할 것
- **반영(`apply.mjs --write`)은 선생님이 미리보기를 보고 "반영해"라고 한 뒤에만.** 반영하면 학생의 시험 화면에 점수·사유가 바로 보인다.
- 채점 파일(학생 이름·답안)은 `~/exam-grading/` 아래에만 둔다. **레포에 넣거나 커밋하지 않는다.**
- 선생님 기준에 없는 판단은 지어내지 않는다. 애매하면 점수는 채우되 `확인필요` 칸에 이유를 적는다(그 학생은 반영 때 자동으로 건너뛴다).
- `사유`는 학생에게 그대로 보인다 — 학생이 읽을 말투로, 짧게, 기준의 어떤 요소가 빠졌는지. 정답을 통째로 적지 않는다.
- 선생님에게는 한국어로 짧게 보고한다.

## 순서
1. **시험 고르기** — `node tools/exam-grading/list.mjs [제목 일부]` 로 배정 목록(asId, 대상, 제출·채점대기 수)을 보여주고 어느 배정을 채점할지 확인한다. 같은 시험을 여러 반에 배정했으면 `--exam <examId>` 로 한 번에.
2. **내보내기** — `node tools/exam-grading/export.mjs <asId…>` 또는 `--exam <examId>`. 폴더 경로를 알려준다.
   - `questions.md`(문항·배점·보기·정답·테스트케이스), `grades.csv`(학생×문항), `students.csv`(제출/미제출).
   - 객관식은 정답 여부로, 코드형은 테스트 통과 비율로 `점수`가 미리 채워져 있다. 서술형·단답형은 빈칸.
3. **기준 확인** — 선생님이 준 채점 기준/평가계획을 `questions.md` 의 문항에 맞춰 문항별로 정리해 보여준다(배점·요소·부분점수·허용 답). 빠진 문항·배점이 안 맞는 곳은 물어본다.
4. **시범 채점** — 학생 5명 정도만 먼저 채점해서 표로 보여준다(학번·문항·점수·사유). 선생님 피드백으로 기준을 고친다.
5. **전체 채점** — `grades.csv` 의 `점수`·`사유`·`확인필요` 칸을 채운다. 다른 열은 바꾸지 않는다.
   - 미리 채워진 객관식·코드 점수도 기준과 다르면 고친다(예: 부분 점수 규칙).
   - 많으면 문항 단위로 나눠서 채점한다(같은 문항을 연달아 보면 일관성이 좋다).
6. **검토용 시트** — 구글 시트 도구가 있으면 `grades.csv` 로 새 시트를 만들어 링크를 준다(제목 예: "<시험 제목> 채점 검토"). 없으면 CSV 경로를 알려준다.
   선생님이 시트에서 고쳤다면, 반영 전에 시트 값을 다시 읽어 `grades.csv` 에 덮어쓴다(열 순서 그대로).
7. **미리보기** — `node tools/exam-grading/apply.mjs <폴더>/grades.csv` (쓰지 않음). 반영/새로 공개/건너뜀 인원과 건너뛴 이유를 보고한다(`apply-preview.csv`).
8. **반영** — 선생님이 확인하면 `node tools/exam-grading/apply.mjs <폴더>/grades.csv --write`. 결과를 보고한다.
   - 관리자 화면 시험 → 결과 조회에서 점수가 보이고, 학생 시험 화면에도 공개된다.
9. **시험 점수 확인으로 넘기기(선택)** — 관리자 → 시험 점수 확인 → **시험에서 가져오기** 에서 이 시험을 고르면 문항별 점수·사유가 평가로 들어온다. 반별 공개·이의신청은 거기서.

## 문제가 생기면
- `firebase CLI 로그인…` 오류: 선생님에게 터미널에서 `firebase login --reauth` 를 부탁한다.
- `건너뜀: grades.csv 에 없는 문항`: 학생 답안 줄을 지웠거나 내보낸 뒤 문항이 바뀐 것 — 다시 내보낸다.
- 반영 후 되돌리기: 같은 파일에서 점수를 고쳐 다시 `--write`(이전 값으로). 학생을 다시 비공개로 돌리는 기능은 없다.
