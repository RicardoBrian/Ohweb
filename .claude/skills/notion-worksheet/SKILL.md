# 노션 페이지 작성

규칙과 카테고리별 양식은 `ohnotion/TEMPLATE.md` 에 있다. **먼저 그 파일을 읽고** 그대로 따른다. 이 스킬에 규칙을 따로 적지 않는다(두 군데가 어긋난다).

## 순서
1. 카테고리를 정한다 (개념 학습지 / 실습 / 수행평가 안내 / 허브 / 연수 자료). 애매하면 묻는다.
2. 새로 만들 때: 내용에 필요한 자료(수업 주제, 범위, 링크, 사진)가 부족하면 묻는다. 지어내지 않는다.
   고칠 때: 노션 fetch 로 현재 내용을 읽고, 내용은 그대로 두고 **형식만** 규칙에 맞춘다. 문장을 새로 쓰거나 지우려면 먼저 말한다.
3. 노션 Notion-flavored Markdown 으로 쓴다. 칸은 `<callout icon="👉" color="blue_bg">`, 링크 버튼은 칸 안 `### [제목 열기](https://…)`.
   기존 페이지에서 `update_content` 로 바꿀 때는 긴 주소를 빼고 짧은 부분(`[2-1 누르기]`)만 `old_str` 로 쓴다. 사진 블록이 든 칸은 이 방법으로 안 풀리니 건드리지 않는다.
   순서도가 필요하면 `ohnotion/tools/flowchart/README.md` 의 규칙대로 JSON 을 만들어 `flowchart.py` 로 HTML 을 뽑는다. 언어 페이지마다 그 언어 파일을 쓴다.
4. 만든 뒤 페이지 링크를 주고, 규칙에서 벗어난 부분이 있으면 말한다.

## 지킬 것
- 학생에게 열려 있는 페이지(통합이 연결된 페이지)는 고치면 2분 안에 학생 화면에 바뀐다. 기존 페이지를 고치기 전에 어떤 페이지를 어떻게 바꿀지 알린다.
- 여러 페이지를 한꺼번에 고칠 때는 1개를 먼저 고쳐 보여 주고 승인 받은 뒤에 나머지를 한다.
- 사진·파일 블록(`notion-file-block://`)은 주소를 그대로 둔다. 지우거나 다시 올리지 않는다.
- 노션에서 못 그리는 블록(사이트 기준)은 쓰지 않는다. 목록은 TEMPLATE.md.
- 선생님에게는 한국어로 짧게 말한다.
